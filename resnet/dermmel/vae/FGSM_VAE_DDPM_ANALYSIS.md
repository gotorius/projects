# FGSMにおけるVAE vs DDPM防御性能の分析

## データの確認

### FGSMでの防御性能

| 防御手法 | FGSM精度 |
|---------|--------|
| **DDPM** | 73.8% |
| **VAE** | 74.0% |
| **差分** | +0.2% (VAE > DDPM) |

VAEがDDPMをわずかに上回っています。

---

## 1. なぜVAEがFGSMで効果的なのか？

### 攻撃の複雑さと防御の適合性

```
【FGSM: 最も単純な敵対的攻撃】

x_adv = x + ε·sign(∇_x L(f(x), y))
        ↑
    勾配方向に1ステップ進むだけ
    単純で予測しやすい摂動パターン
```

### VAEの特性：単純だが効果的

```python
# train_vae.py より

# VAEの再構成メカニズム
def reconstruct(self, x):
    mu, _ = self.encoder(x)
    return self.decoder(mu)
```

**VAEが有効な理由**：

1. **高速な投影**
   ```
   敵対的画像 → Encoder → 潜在空間 → Decoder → 浄化画像
   
   潜在空間での投影が敵対的摂動を効果的に除去
   ```

2. **再構成品質重視（β=0.01）**
   ```python
   # β-VAEの設定
   beta_max = 0.01  # ← KL項を極端に小さく
   ```
   
   FGSMのような単純な摂動パターンに対して、
   忠実な再構成が敵対的摂動を「上書き」できる

3. **Discriminator補強**
   ```python
   total_loss = (recon_loss + 
                beta * kl_loss +
                λ_perceptual * perceptual +
                λ_ssim * ssim +
                λ_edge * edge +
                λ_adv * adv_loss)  # ← GANで品質向上
   ```
   
   高品質な再構成 = FGSMの勾配摂動を効果的に除去

---

## 2. なぜDDPMがより強力な攻撃に強いのか？

### 攻撃難度の増加に対する対応力

```
【攻撃の複雑さ】

FGSM:        単純（1ステップ、勾配方向）
    ↓
PGD:         複雑（複数ステップ、反復最適化）
    ↓
AutoAttack:  非常に複雑（複数の攻撃を組み合わせ）
             - APGD-CE
             - APGD-T
             - FAB-T
             - Square Attack
```

### DDPMの強さ：複雑な再構成プロセス

```
【DDPM: 逆拡散プロセス】

敵対的画像
  ↓ ノイズを何度も追加・除去
  ↓ 複数ステップ（例：1000ステップ）
  ↓ 各ステップでマニフォルド学習
  ↓
浄化画像

結果：複雑な攻撃に対して多層的に対抗できる
```

### データから見える傾向

```
|        | FGSM | PGD  | AutoAttack |
|--------|------|------|-----------|
| VAE    | 74.0 | 74.0 | 75.6      | ← 大幅な改善なし
| DDPM   | 73.8 | 84.8 | 92.0      | ← 攻撃が強まると大幅改善
```

**解釈**：
- **FGSM（簡単）**: VAE ≈ DDPM（どちらも対応可能）
- **PGD（複雑）**: DDPM > VAE（DDPMの複雑な再構成が有利）
- **AutoAttack（最複雑）**: DDPM >> VAE（差が大きく開く）

## 3. 防御手法の適応範囲

### 防御の「適応性」を図解

```
【防御性能 vs 攻撃複雑度】

        │
   100% │         DDPM ╱╱╱╱╱╱
        │           ╱╱╱╱
        │         ╱╱╱
        │       ╱╱ VAE ━━━━━
        │     ╱╱ ╱
    70% │   ╱╱╱
        │ ╱╱╱
        │────────────────────→
          FGSM PGD AutoAttack
          （攻撃の複雑度）
```

### VAEの特性
- **得意**: 単純な攻撃（FGSM）→ 高速で効率的
- **苦手**: 複雑な攻撃（PGD, AutoAttack）→ 単純な再構成では不足

### DDPMの特性
- **得意**: 複雑な攻撃（PGD, AutoAttack）→ 多層的に対抗
- **苦手**: 推論が遅い（複数ステップ）

## 4. なぜこんなことが起こるのか？

### 原理的な理由

```
【FGSM攻撃の性質】

敵対的画像 = クリーン画像 + ε·sign(∇L)
           ↑
        「方向性のある」単純なノイズ

敵対的摂動の形状：
- ほぼ一方向（勾配方向）
- パターンが単純で予測可能
```

### VAEの対抗メカニズム

```
【VAEによる防御】

Encoder: 「この画像のコア特徴を抽出」
         → FGSM摂動（高周波ノイズ）を捨てられる

潜在空間: クリーン画像のManifold付近に投影
         → 敵対的摂動は除去される

Decoder: 「Manifoldから最も尤もらしい画像を再構成」
         → 高品質な浄化画像を生成
```

**結果**: FGSMのような単純で予測可能な摂動には、
VAEの「潜在空間投影」が非常に効果的

---

## 5. DDPMがFGSMで劣る理由（わずかだが）

### 過度な設計

```python
【DDPM: 複雑な逆拡散プロセス】

敵対的画像 → 1000ステップの逆拡散 → 浄化画像
         ↑
    「複雑さが必要ない」レベルの攻撃

結果：オーバーエンジニアリング状態
     計算コストをかけた割に、
     VAEと同程度の効果
```

### 実装上の理由

```
【DDPM vs VAE】

DDPM:
- 複雑な逆拡散学習
- 多数のステップで段階的に再構成
- 全般的には堅牢だが、単純攻撃では「力を入れすぎ」

VAE:
- シンプルな潜在空間投影
- 直接的で効率的
- FGSMのような単純な摂動に最適化
```

## 6. 実用的な含意

### 攻撃難度別の推奨防御手法

```
【敵対的防御の選択】

FGSM（簡単な攻撃）
  → VAE推奨（高速、十分な効果）
  → メリット：計算量少ない、リアルタイム対応

PGD（中程度の攻撃）
  → DDPM推奨（より高い精度）
  → メリット：攻撃に対して堅牢

AutoAttack（強力な攻撃）
  → DDPM必須（VAEでは不足）
  → メリット：最高レベルの堅牢性
  → デメリット：計算時間が長い
```

## 8. なぜこのような違いが出るのか？（理論的説明）

### Manifold仮説の観点から

```
【MagNet方式の敵対的防御理論】

「敵対的摂動はManifold外にある」

クリーン画像のManifold:
  ┌─────────────────┐
  │   複雑な曲面    │  ← DDPMは複雑な曲面を学習
  │  高次元的    │
  └─────────────────┘
        ↑
    敵対的画像はここから外れている
```

### VAEの場合

```
VAEは「単純な再構成」で投影
→ FGSMのような単純な摂動には効果的
→ 複雑な攻撃には不足
```

### DDPMの場合

```
DDPMは「多層的な逆拡散」で投影
→ 複雑な摂動パターンも段階的に除去
→ より強力な攻撃に対応可能
```

## 9. 結論

### FGSMでVAEがDDPMを上回った理由

**1つの言葉で**: **「攻撃の複雑さに対する最適化レベルの差」**

```
FGSM（単純）
  ↓
VAE: 「これで十分」→ 74.0%
DDPM: 「複雑な再構成は不要」→ 73.8%
  ↓
→ VAEがわずかに上回る
```

### より強い攻撃でDDPMが優位な理由

```
AutoAttack（複雑）
  ↓
VAE: 「単純な再構成では対応不足」→ 75.6%
DDPM: 「複雑な逆拡散で対抗」→ 92.0%
  ↓
→ DDPMが大幅に上回る
```

### 実用的なメッセージ

**「すべての防御手法が、すべての攻撃に同じレベルで対応できるわけではない」**

- VAE: 軽量・高速・単純な攻撃向け
- DDPM: 重量・低速・複雑な攻撃向け
- GAN: 中程度のバランス
